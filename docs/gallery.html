A request retries twice, then gives up

State machineFire eventsGuards on the arrows

A client sends a request. If no reply comes in time, it waits a moment and tries again, up to three tries. Fire the events below and watch where the same event leads depending on how many tries are left. It plays one run on its own first.

A cache miss costs a trip to the database

SequenceDrag the playheadTips

Time runs down. The API checks the cache first; on a miss it asks the database and saves the answer for next time. Drag the playhead knob on the left, or use the scrubber. Hover a message to see what it carries.

A focus pulls in only what is near it

Particle fieldDraggable focusSettings

Particles follow a smooth flow. Inside the ring they are pulled toward its center; outside it, nothing changes. Drag the ring to move it and its knob to resize it. Strength and field scale are in the settings.
