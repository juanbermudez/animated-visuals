Inspiration and adapted ideas

  • diagram-design is Cathryn Lavery's MIT-licensed diagram taxonomy, adapted here with motion and interaction guidance.
  • pmndrs math is an MIT-licensed geometry and simulation library whose data-oriented approach informs the WebGL guidance.
  • gpgpu-curl-noise-dof is an MIT-licensed Poimandres example that informed the per-point depth-of-field approach.
  • Alex Zhang's blog figures provided interaction patterns for study; no code is included, and the source notice does not state a software license.
  • interface-design guidance combines MIT-licensed guidance from jakubkrehel/skills and Vercel's Web Interface Guidelines.
  • OKLab and the W3C CSS Color 4 matrices define the color conversion used by the theme tools; no source code is included.
  • Konsistent is Vercel Labs' optional Apache-2.0 structural linter.
  • SapiMouse is the mouse-dynamics dataset used for summary statistics in the interaction guidance; no recorded data is included, and the source notice does not state a dataset license.

Libraries the guidance works with

  • nivo is an MIT-licensed chart library and is not bundled.
  • three.js is an MIT-licensed WebGL library and is not bundled.
  • react-three-fiber is an MIT-licensed React renderer for three.js and is not bundled.
  • drei is an MIT-licensed helper library for react-three-fiber and is not bundled.
  • @react-three/postprocessing is an MIT-licensed post-processing library and is not bundled.
  • maath is an MIT-licensed motion-math library compared with pmndrs math in the guidance and is not bundled.
  • MediaPipe provides the Apache-2.0 pose landmarker used for tracing people as geometry and is not bundled.
  • Mermaid is an MIT-licensed diagram library supported by the fill expansion mode and is not bundled.
