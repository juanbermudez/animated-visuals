One spec per figure

A figure is FS.figure(id, spec) on a canvas or SVG inside a plate. The spec says how tall it is, what state it has and how to draw that state; the runtime adds the clock, controls, settings, tips, expand and keyboard support. Every sample on this page is the code that runs it.

The plate

A plate is plain HTML: a head with the claim, a stage with the drawing, an optional toolbar and caption. Controls are attributes, so they need no glue code.

<figure class="fs-plate">
  <header class="fs-head"><h3 class="fs-title">The claim, as a sentence</h3><span class="fs-status">Illustration</span></header>
  <div class="fs-stage"><canvas id="my-fig"></canvas></div>
  <div class="fs-toolbar">
    <span class="fs-position" data-fs-out="my-fig:t"></span>
    <div class="fs-controls"><div data-fs-seek="my-fig"></div><button data-fs="my-fig play"></button></div>
  </div>
  <p class="fs-caption">What is measured or made up, and how to play with it.</p>
</figure>

Load themes/base.css, one token layer such as themes/default.css, and assets/runtime/fs-runtime.js. The standalone starter assets/plate-template.html has all three inlined.

The spec

OptionWhat it does
height(w)The drawing's height in CSS px for a width. Switch layouts at narrow widths instead of shrinking text.
duration, loopA timeline of fixed length that plays once to its payoff, or loops. Leave both out for an endless process.
paramsNamed values that ease toward their targets. Numbers become sliders, booleans switches, options segmented buttons. They go in the settings popover unless placement: "inline"; hidden: true keeps one out.
handlesParts of the drawing the reader drags: get, set, bounds, optional release and radius. Keyboard and touch included; past the bounds they rubber-band and spring back.
stepsDiscrete states with captions. Draw the change from f.from to f.step with f.stepT going 0 to 1.
chaptersStops on a timeline, for the arrow keys, chapter buttons and the scrubber's marks.
timeAxis(f)Maps time onto the drawing, so the figure itself scrubs: hover to preview, drag, click to jump, flick to coast.
tips, tipAtShort explanations for drawn parts, after a hover delay and at once on keyboard focus.
reserveThe widest text each output can show, so changing numbers never push the layout around.
expand"fit" (default) scales the plate up to 84% of the viewport with the same layout. "fill" lays it out again at the new width. false removes the button.
autoplay, keyframe, settleWhether it starts when scrolled into view, and what a reader with reduced motion sees: a timeline's keyframe, or a process run settle seconds ahead.
formatTime, stepDurationHow time reads in outputs and the scrubber; how long a step change takes (0.48 s).
init, update, renderHooks, plus resize, onParam and onStep. render(f, ctx) draws only from state: f.t, f.step, f.v (eased params), f.hover, f.drag, f.w, f.h and the theme in f.C.

Samples that run

params

The one control that is the interaction sits in the toolbar. Everything else lives behind the settings icon in the plate's corner.


  


  
handles

  
If a value has a place in the drawing, the reader drags that place. Drag past the dashed box and let go.

  

    



  


  
steps

  
Each step changes one thing. Captions stack in one box, so it never changes height.

  

    



  


  
chapters and timeAxis

  
A timeline is a function of one clock. With timeAxis, the drawing is the scrubber; the toolbar scrubber, the arrow buttons and the keys all glide the same clock.

  

    



  


  
tips and tipAt

  
Hover a bar and wait half a second. Once one tip is open, the next opens at once. In HTML or SVG, data-fs-tip does the same with no code.

  

    



  


  
reserve

  
Drag the slider from 0 to the end. The words after the number stay where they are, because the number keeps the width of its widest value.

  

    



  


  
expand: fit and fill

  
Open both from their corners. Fit, the default, scales the plate up and keeps its layout, so proportions never change; the canvas renders at the larger size. Fill lays the figure out again at the wider width, which suits drawings that reflow, like a Mermaid diagram or this grid.

  

  

    
    
  

  




  


  
Events

  
Figures report what happens to them. This listens to three figures above; use any of them and watch this line:

  
Waiting for an event…




  
The events are play, pause, end, seek, scrub, step, param, reset, hover, dragstart, drag, dragend and expand. on() returns a function that removes the listener.


  
The FS API

  
Anything a reader can do, code can do, through the same path. Each button below runs the line on it.

  

    
    
    
    
    
    
    
    
    
  

  
Click a line to run it.

  

    

      
CallWhat it does

      
        
play(), pause(), toggle()Run or hold the clock. A finished timeline replays from the start.

        
seek(t, { animate })Jump to a time, or glide there on a spring that keeps its speed if you retarget.

        
chapter(±1)Glide to the next or previous stop.

        
goto(n), next(), prev()Move between steps.

        
set(name, value)Change a param; pass an object to set several, and { instant: true } to skip the ease.

        
state(), apply(state)Read or restore { t, step, params, playing }: presets, shared links, tests.

        
out(name, text)Write a computed value to every data-fs-out="id:name", in the figure or the prose.

        
hover(key)Light a part, the same way a linked word does.

        
expand(), collapse(), openSettings()Open the plate full screen or its settings.

        
redraw(), dispose()Ask for a frame; release observers when a page or component goes away.

        
FS.get, FS.listFind figures by id.

        
FS.setTheme, FS.setModeSwitch the theme for the page, or pass an element to theme just that one.

        
FS.k, FS.ease, FS.rngThe drawing kit (text, labels with halos, hatching, brackets, playheads), easings, a seeded random generator. Also FS.window, FS.spring, FS.rubber, FS.slider.

<span data-fs-out="demo-curve:bump"></span> tall.

  
The other bindings: data-fs="id play|next|prev|reset|chapter-next|chapter-prev" on buttons, data-fs-param="id:name" for a slider, data-fs-seek="id" for a scrubber, data-fs-dots="id" for step dots and data-fs-tip for an explanation on any element.


  
React

  
assets/react/ wraps the same runtime, so figures behave the same in a Next.js site. The hook mounts a figure and disposes it on unmount; never set React state per frame.

  

    

      
FileWhat

      
        
useFigure.tsuseFigure(id, spec) loads the runtime in the browser, mounts the figure and returns its controller.

        
FigurePlate.tsxThe plate markup with the data-fs* bindings wired.

        
FlowDiagram.tsxA stepped architecture diagram with packets, two layouts.

        
ExplorableLine.tsxA nivo line chart with one parameter and direct labels.

        
FocusField.tsxA react-three-fiber particle field with a depth-of-field focus pull.

        
nivo-theme.tsA nivo theme on the --fs-* tokens, plus reduced-motion and token hooks.

    render(f, c) { /* the same render as the params sample */ },
  });
  return (
    <FigurePlate id="wave" title="A wave you can tune" status="Illustration" params={[{ name: "amp", label: "Height" }]}>

    </FigurePlate>
  );
}

Writing styles

  
Every label, caption and tip follows one writing style per page. Practical is the default: plain words, a stance first, a moment the reader has lived. Academic is for papers: formal, numbered, with units, n and uncertainty. Ask for academic and the agent switches.

  

    

      
PracticalAcademic

      
        
Independent actions run at the same timeIndependent actions execute concurrently

        
2.3× longer2.28× longer than the concurrent schedule (sum of measured durations)

        
Hover a block to see what it isHover to inspect each component's definition.
