Agent skill for Claude Code and Codex · MIT

Figures your readers can play with, built by your agent.

Animated Visuals teaches an agent to make small, polished figures that move and respond: architecture flows with packets, step-by-step mechanisms, timelines you scrub, charts with handles you drag. Every figure runs on one runtime with no dependencies, so buttons, words in your text and your own code all drive it the same way.

Install

The skill is a folder of instructions, a runtime and themes. Clone it where your agent looks for skills.

  1. Claude Code 
    git clone https://github.com/juanbermudez/animated-visuals ~/.claude/skills/animated-visuals
  2. Codex 
    git clone https://github.com/juanbermudez/animated-visuals ~/.codex/skills/animated-visuals
  3. Ask for a figure. Describe the claim, not the chart. For example: “Make an interactive figure showing how our job queue backs up when there are too few workers.” The agent picks the form, writes the copy, themes it and checks it in a browser.

How it works

A figure is a function of its state: one clock, a step and a few named parameters that ease toward their targets. Play, scrub, step, a slider, a word in the prose and a line of code all change that state through one controller, so any moment can be shown, linked to and tested.

const fig = FS.figure("fig-hero", { height, steps, render(f, ctx) { /* draw from f.t, f.step, f.v */ } });
fig.next();                 // what the Next button does
fig.seek(4.8, { animate: true });
fig.set("workers", 3);      // what a slider or a dragged handle does
FS.get("fig-hero").state(); // { t, step, params, playing }

Read more on the customize page, or open any figure in the gallery and try FS.list() in the console.
