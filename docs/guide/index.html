Guide

Guide turns a topic, paper, codebase or decision into one self-contained HTML page. It combines practical writing, a fixed explanatory structure, source checks and live figures from Animated Visuals.

Install

npx skills@latest add juanbermudez/skills --skill guide -g

Workflow

  1. Brief the audience, outcome, example, scope and reading length.
  2. Write and check the plan before any HTML.
  3. Choose the guide type and place it on the section skeleton.
  4. Write the explanation in a plain practical voice.
  5. Build each necessary figure with Animated Visuals.
  6. Build one self-contained HTML file.
  7. Run browser, term, copy, number and reader checks.
  8. Deliver the file and name anything not verified.
