Themes

One figure, 27 looks

Figures read only --fs-* tokens, so a theme is one block of CSS variables. Each card below is pinned to its own theme, so you can compare them side by side; Use applies one to this whole page, the same as the sun or moon button.

Default is monochrome, with ink as the accent. Notebook swaps in mono figure text, uppercase heads, square corners and an amber focus, for paper explainers. The other 23 are palettes from Omarchy's themes, with contrast fixed where needed: muted text reaches 4.5:1, the accent and categories 3:1.

Clear the search and filters to see all 27 themes.

Tokens

This is the whole contract. Canvas figures read the colors as f.C (f.C.fg, f.C.accent, f.C.c[0]); SVG and HTML use var(--fs-…). The swatches show the theme you picked and change with it.

--fs-surfaceThe plate, and the halo behind labels drawn over marks.
--fs-surface-2Hover and raised surfaces. Also the default color of the 4px frame band.

--fs-mutedSecondary text, ticks, connectors. At least 4.5:1 on the page.

--fs-strongThe strongest ink: playheads and emphasis.
--fs-accentFocus: the one or two things that matter now, handles, focus rings. At least 3:1 on the plate.
--fs-c1 to --fs-c6 Categories, each at least 3:1. Grays in Default, so pair them with labels or textures.

--fs-font-figureText inside figures. Also --fs-font-body, --fs-font-display, --fs-font-mono.

--fs-radiusPlate corner (12px). --fs-radius-inner and --fs-radius-control for what sits inside.
--fs-frame-widthThe frame band (4px). --fs-frame sets its color.
--fs-stroke-*hair 1, edge 1.1, series 1.75: line widths for grids, connectors and data.
--fs-dimOpacity for context that is not the point right now (0.28).
--fs-dur, --fs-easeControl feedback timing (240ms, a soft ease out). Also --fs-dur-step, --fs-ease-spring, --fs-shadow, --fs-control-size.

Write a theme

Copy a block, rename it and change the values. Colors are written in OKLCH (lightness 0 to 1, chroma, hue in degrees); scripts/hex-to-oklch.mjs converts a theme written in hex. Keep muted text at 4.5:1 on the page and the accent and categories at 3:1 on the plate. This one is defined in this page's own CSS, and the figure under it uses it:


  

  
Apply it


FS.setTheme("harbor");      // the whole page: sets data-fs-theme on <html>
FS.setTheme(null);          // back to Default
FS.setMode("light");        // Default and Notebook come in light and dark


<!-- one figure only -->
<figure class="fs-plate" data-fs-theme="nord"> … </figure>


/* or override single tokens after the theme layer, for the page or one plate */
.fs-plate { --fs-radius: 4px; --fs-accent: oklch(0.70393 0.19154 37.126); }


  
Animate the switch

  
This site tweens every theme change. The color tokens are registered with @property so they can transition, and the transition runs on <html>. While <html> has a running animation, the runtime re-reads the tokens every frame and redraws, so canvases change with the page instead of snapping at the end.


@property --fs-bg { syntax: "<color>"; inherits: true; initial-value: oklch(0.21342 0 0); }
/* … one per color token … */
:root { transition: --fs-bg 520ms cubic-bezier(0.16, 1, 0.3, 1) /* , … */; }


  
Bridge to your site's tokens

  
Inside a site that already has a palette, don't pick a theme: map the figure tokens to the site's own variables once, instead of loading default.css. Then the site's light and dark modes and its palettes flow into every figure. The runtime resolves var() chains and color-mix() through a probe element, so canvas figures follow too, and it re-reads tokens when <html> changes its class, data-fs-theme, data-fs-mode or data-style-palette. This is the example bridge, themes/site-bridge.css; replace the --site-* names with your site's variables:



/* Example bridge: load this instead of default.css inside a site that already has design tokens, so the
   figure tokens follow the site's own variables and its light/dark modes and palettes flow into every figure.
