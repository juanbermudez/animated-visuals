# Sources

- [Diátaxis compass](https://diataxis.fr/compass/) — separates tutorial, how-to, explanation, and reference work.
- [Diátaxis explanation](https://diataxis.fr/explanation/) — explains why reflective explanation and instruction should stay apart.
- [Divio documentation system](https://docs.divio.com/documentation-system/) — presents the same four documentation modes.
- [IES practice guide: Organizing Instruction and Study to Improve Student Learning](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) — evidence for worked examples, integrated words and graphics, concrete and abstract representations, quizzes, and explanatory questions.
- [Explorable Explanations](http://worrydream.com/ExplorableExplanations/) — supports letting readers change the assumptions a claim depends on.
- [Nicky Case on explorable explanations](https://blog.ncase.me/explorable-explanations/) — supports using interaction only where it explains better than text or images.
- [Research Debt](https://distill.pub/2017/research-debt/) — argues that explanation transforms an idea instead of merely restating it.
- [3Blue1Brown FAQ](https://www.3blue1brown.com/faq/) — supports concrete examples before general frameworks, definitions as an endpoint, and deliberate motion.
- [Google developer documentation style](https://developers.google.com/style/highlights) — supports second person, active voice, and conditions before instructions.
- [GOV.UK on the 25-word sentence limit](https://insidegovuk.blog.gov.uk/2014/08/04/sentence-length-why-25-words-is-our-limit/) — source for flagging sentences over 25 words; the post is from 2014 and may not reflect current policy.
- [Write the Docs documentation principles](https://www.writethedocs.org/guide/writing/docs-principles/) — supports prerequisites first and accuracy over completeness.
- [Anthropic doc coauthoring skill](https://github.com/anthropics/skills/blob/main/skills/doc-coauthoring/SKILL.md) — source for independent reader testing with predicted questions.
- [Animated Visuals](https://github.com/juanbermudez/skills/tree/main/skills/animated-visuals) — source for claims-first figures, interaction, themes, motion, and browser verification.
- Owner's local `teach-me` skill — source for the plan file, terms audit, running example, labelled fact sheet, application checks, and honest learning-science caveats; local source, no public link verified.
